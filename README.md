# Bounce Duel

A 2-player game: two white cubes bounce around a black screen like the old DVD logo.

- Both players type a name, which is shown above their cube.
- Each player clicks where their cube starts, then clicks again to pick the direction it bounces.
- A spike orbits around each cube. Every hit from your spike on the other cube does 1 damage.
- The cubes bounce off the walls and off each other.
- Both cubes start with 100 HP. The first to bring the other to 0 wins.
- The cubes speed up over time so matches don't drag on.

Open `index.html` in a browser to play (mouse or touch).

## On your phone

The `mobile/` folder is an Expo app that wraps the game. See [`mobile/README.md`](mobile/README.md) for how to open it in Expo Go.
